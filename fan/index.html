Measured by camera from the floor. One baseline plus three test weights — not one per blade.

How this goes

The phone has to sit still and stay put for all four readings. Lay it on the floor pointing up, or lean it on something. Holding it cannot work — to a camera your hand shaking and the fan wobbling are the same thing. Move it between readings and the readings stop comparing.
  1. Turn the fan's light on and point the phone at it. It finds the light by itself — the circle turns teal when it has it. (Tap the screen only if it grabs the wrong thing.)
  2. Press Record, then set the phone down and let go. It waits until the phone is completely still before it starts counting, so there is no rush.
  3. Run the fan at the speed that bothers you, and use that same speed all four times.
  4. Four readings: one with nothing added, then one each with the test weight on three different blades.

Your fan

no closer in than and no further out than inches from the center

Closer in than the first number you'd hit the light or the motor. The second can go all the way out to the blade tip if you can clip the outer edge. Rough numbers are fine — this only stops it suggesting a spot that doesn't exist.

Measure radius from any repeatable datum — the edge of the light housing is fine. You do not need the true center: the answer comes back at the same radius you put the trial weight, so a consistent offset cancels out.

Use the same fan speed every time — vibration grows with the square of speed, so mixing speeds corrupts the maths. Use the speed where the wobble bothers you. The phone must sit still for all four readings — the camera position is the reference everything is measured against.

What to add

Before you chase the last of it

Balancing corrects mass. It cannot correct tracking — a blade sweeping a different plane. Stand a yardstick under the blade path so it just grazes one tip, rotate the fan by hand, and check every tip passes at the same height. More than about ⅛ in of variation is tracking, and no weight will fix it: bend that blade's iron instead.

If wobble peaks at one speed and eases above it, that's resonance in the downrod, not imbalance — weights won't help. Wobble that just grows with speed is imbalance, and this tool applies.
